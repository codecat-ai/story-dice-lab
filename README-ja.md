# Story Dice Lab

[English](README.md) | [中文](README-zh.md) | [日本語](README-ja.md)

Story Dice Lab は、決定的に再現できる創作プロンプトを振るためのローカルファーストなブラウザーアプリです。

## 課題と動機

作家、教師、テーブルトークの進行役は、アカウントやネットワーク接続なしで、遊び心があり再現できて共有しやすいプロンプトをすばやく必要とすることがあります。

## 機能

- 6 種類のプロンプトダイス：人物、目的、舞台、障害、物、ひねり。
- シードによる決定的なロールで、ワークショップの prompts を再利用可能。
- すべてのダイス、または 1 つのダイスだけを振り直し可能。
- ダイスをロックして、「全体を振り直す」ときに良い案を保持。
- コンパクトなプレーンテキストのプロンプトをコピー可能。
- 6 種類すべてのダイスを使い、オープニングイメージ、欲求、複雑化、転換点、エンディングフックを含む決定的な 5 ビートの場面アウトラインをコピー可能。
- シード、6 種類のダイス、場面作りのための 3 つの問いを含む、決定的で印刷しやすいワークショップ配布資料をコピー可能。
- 決定的な進行役用アジェンダをコピー可能。編集できるタイトルと合計分数、時間配分された段階、ダイスカテゴリを場面の判断につなげるメモを含みます。
- アジェンダの各段階に対応した進行役向けタイマーカードをコピー可能。同じ合計分数で拡大縮小され、ライブ進行でチェックしやすい形式です。
- アジェンダのタイトルと拡大縮小された段階時間を使い、破線の切り取り線付きで進行役用タイマーカードレイアウトを印刷可能。
- 同じアジェンダ段階から作られる、教室内投影向けの大きな文字の進行役タイマー表示を利用可能。前へ、次へ、リセットのボタンで手動操作できます。
- 決定的な教室向け推敲カードを、編集できるタイトル付きでコピー可能。各ダイスに 1 枚ずつ、現在の値、推敲タスク、短い振り返りの問いを含みます。
- 教室向け推敲カードレイアウトを破線の切り取り線付きで印刷可能。各ダイスカテゴリに 1 枚ずつ、同じタイトル、シード、現在のロールを使います。
- 決定的な小グループ相互講評ロールカードを、編集できる講評ラウンドのタイトル付きでコピー可能。現在のダイスを使った進行しやすい役割タスクを含みます。
- 小グループ相互講評ロールカードレイアウトを破線の切り取り線付きで印刷可能。
- 講評後のコンパクトで決定的なアクションプランをコピー可能。編集できるタイトル、優先順位付きの 3 つの次ステップ、締めの推敲コミット行を含みます。
- Markdown の影響を受ける文字をダイス値でエスケープし、同じワークショップの問いを含む Markdown プロンプトをコピー可能。
- 現在のプロンプトを、操作 UI を隠したワークショップ向けブラウザー印刷シートとして印刷可能。
- シードとロック済みダイスを復元できる共有用 URL ハッシュをコピー可能。
- 6 種類のダイスカテゴリに対応したカスタム JSON 単語リストをインポートし、正規化済み JSON をコピー/エクスポート可能。
- クラス、ジャンル、ワークショップグループごとに、任意メモ付きの名前付きローカル単語リストプリセットをブラウザー保存へ保存、読み込み、削除可能。
- 組み込みの教室セッションテンプレートを適用し、繰り返し使うワークショップ用のシード、アジェンダタイトル、合計分数、テンプレート単語リスト、利用メモを事前入力可能。
- 現在のダイス、現在のタイマー段階、プリセットメモ、チェックした教室用成果物の抜粋をまとめた、ローカルな Markdown 進行セッションスナップショットをコピー可能。
- 紙のワークショップ記録用に、現在の進行セッションスナップショットをコンパクトなブラウザーシートとして印刷可能。
- 任意の進行役タグとアーカイブラベル付きで直近 10 件までのローカルセッションスナップショットをブラウザー履歴に保存し、タグまたはアーカイブラベルで記録を絞り込み、保存済みスナップショットの詳細パネルを開いて、現在のダイス結果を置き換えずに古い記録をコピーまたは印刷し、表示中の簡潔な履歴リストや移行用の履歴 JSON をコピーし、別ブラウザーから検証済みの履歴 JSON をインポートし、履歴を消去できます。
- ライブ進行用の見えるキーボードショートカットを利用可能：`r` はロックされていないダイスを振り直し、`l` はフォーカス中のダイスのロックを切り替え、`[` と `]` はタイマー段階を移動し、`c` は現在のプロンプトをコピーし、`?` はショートカットヘルプを表示または非表示にします。
- アクセシブルでキーボード操作しやすいコントロール。

## インストール

Story Dice Lab は GitHub のみで公開されています。npm には公開していないため、検証済みの `npm install -g` や `npx` コマンドはありません。

```bash
git clone https://github.com/codecat-ai/story-dice-lab.git
cd story-dice-lab
npm ci
```

## クイックスタート

```bash
npm run dev
```

ターミナルに表示されるローカルの Vite URL を開きます。

`?` を押すか **Show shortcuts** をクリックすると、ライブ進行用ショートカットパネルを表示できます。フォーム入力中、または Ctrl、Meta、Alt を押している間はショートカットは無視されます。

## 例

シード `moonlit workshop` を使い、舞台をロックしてから、場面に合うまで他のダイスを振り直します。教室テンプレートを選び **Apply template** をクリックすると、繰り返し使えるワークショップ用のシード、テンプレート単語リスト、アジェンダタイトル、合計分数を事前入力できます。テンプレート適用時にはロックが解除され、ライブタイマーは第 1 段階に戻ります。**Copy outline** をクリックすると 5 ビートの場面アウトラインをコピーできます。**Copy handout** をクリックすると印刷しやすいワークショップ配布資料をコピーできます。**Copy agenda** をクリックする前にアジェンダのタイトルと合計分数を設定すると、教師やライティンググループの進行役向けの場面スプリントアジェンダをコピーできます。現在の段階を投影するときは、大きなライブタイマー表示の **Previous**、**Reset**、**Next** ボタンを使うか、`[` と `]` でキーボードから段階を移動できます。`r` でロックされていないダイスを振り直し、ダイスカードまたはその操作部品にフォーカスして `l` を押すとそのダイスのロックを切り替え、`c` で現在のプロンプトをコピーし、`?` でショートカットヘルプを表示または非表示にできます。**Copy timer cards** をクリックすると、同じアジェンダ設定で段階ごとのタイマーカードをコピーできます。**Print timer-card layout** をクリックすると、破線の切り取り線付きで段階カードを印刷できます。**Copy revision cards** をクリックする前に推敲カードのタイトルを設定すると、相互フィードバックや 2 回目の執筆に使う 6 枚の推敲カードをコピーできます。**Print revision-card layout** をクリックすると、各ダイスカテゴリに 1 枚ずつ切り取れる推敲カードを印刷できます。**Copy peer role cards** をクリックする前に相互講評ロールカードのタイトルを設定すると、小グループ講評の役割を割り当てられます。**Print peer role-card layout** をクリックすると、切り取れるロールカードを印刷できます。**Copy action plan** をクリックする前にアクションプランのタイトルを設定すると、講評に基づく 3 つの次ステップをコピーできます。必要な成果物抜粋をチェックして **Copy session snapshot** をクリックすると、ワークショップ後の Markdown 記録をコピーできます。**Print session snapshot** をクリックすると同じデータから紙の記録向けのコンパクトなブラウザー印刷シートを開けます。**Save current snapshot** をクリックする前に、クラス、コホート、イベント、ジャンルなどの任意タグをカンマまたは改行区切りで入力し、必要に応じて **Archive label**（classroom、event、draft、assessment follow-up）を選ぶと、現在のスナップショットをローカルセッション履歴へ保存できます。**Filter saved snapshots by tag** または **Filter saved snapshots by archive label** で表示中の保存記録を絞り込めます。表示中の保存済みスナップショットで **View details** をクリックすると、エスケープ済みタイトル、ISO 時刻、タグ、アーカイブラベル、完全な本文を確認でき、**Copy saved snapshot** または **Print saved snapshot** を使って現在のダイス結果を置き換えずに再利用できます。**Copy history list** をクリックすると表示中の保存済みスナップショットの新しい順リストをコピーできます。**Copy history JSON** をクリックすると表示中のバージョン付き移行用 JSON をコピーできます。互換 JSON を **Paste/import history JSON** に貼り付けて **Import history** をクリックすると、このブラウザーの保存済み履歴を置き換えます。**Clear history** をクリックするとこのブラウザーから保存済みスナップショットを削除できます。**Copy Markdown** をクリックするとノートや issue スレッド向けの Markdown プロンプトをコピーできます。**Print prompt sheet** をクリックすると現在のプロンプトのブラウザー印刷フローを開けます。**Copy share link** をクリックすると `#seed=moonlit+workshop&locked=setting` のような URL ハッシュを保存または共有できます。

アウトラインのプレビューには、シードと 5 つのビート（オープニングイメージ、欲求、複雑化、転換点、エンディングフック）が含まれます。これらのビートは、現在のロールの人物、目的、舞台、障害、物、ひねりをすべて再利用します。

アジェンダのプレビューには、シード、6 種類すべてのダイス、選んだ合計分数に合わせて拡大縮小される 5 つの時間配分、人物/目的、障害/舞台、物/ひねりを具体的な場面選択につなげる進行メモが含まれます。

タイマーカードは、アジェンダと同じタイトル、シード、合計分数、拡大縮小された段階時間を使います。コピーされるカードには段階ラベル、短い進行役プロンプト、ライブ進行用のチェックボックス/アクション行が含まれます。印刷レイアウトは同じ決定的なカードデータを 2 カラムのシートに配置し、破線の切り取り線を付けます。

ライブ進行役タイマー表示は、コピー用および印刷用のタイマーカードと同じアジェンダデータを使います。現在の段階ラベル、大きな段階名、分数、進行役プロンプト、アクション確認を表示し、前へ、リセット、次への手動コントロールを備えています。これは意図的に段階送り方式で、MVP ではリアルタイムのカウントダウンは不要です。

推敲カードには、入力した場合はカスタムタイトル、さらにシードと 6 枚の番号付きカードが含まれます。人物は主体性、目的は利害、舞台は感覚描写、障害はエスカレーション、物は具体的な行動、ひねりは結果に焦点を当てます。印刷レイアウトは同じ決定的なカードデータを 2 カラムのシートに配置し、ワークショップで切り取りやすい破線を付けます。

相互講評ロールカードには、入力した場合はカスタムタイトル、さらにシードと 4 つの小グループ役割（Connector、Detail Coach、Stakes Coach、Twist Tracker）が含まれます。各役割は現在のダイスを使うため、講評が一般的な感想ではなく現在のプロンプトに結びつきます。印刷レイアウトは同じ決定的なカードデータを 2 カラムのシートに配置し、破線の切り取り線を付けます。

アクションプランには、入力した場合はカスタムタイトル、シード、番号付きの 3 つの次ステップ、コミット行が含まれます。各ステップは相互講評ロールの焦点をダイスカテゴリへ戻します。Connector は人物/目的、Detail Coach は舞台/物、Stakes Coach は障害/ひねりに対応します。

セッションスナップショットは、ライブセッション後に進行役が貼り付けやすい Markdown 記録です。呼び出し側が指定する日付ラベル、現在のシードとダイス、現在の進行役タイマー段階、現在のプリセット名とメモ、チェックした教室用成果物の短い抜粋を含みます。ユーザー入力フィールドは 1 行に折りたたまれ、Markdown として安全になるよう処理されます。成果物の抜粋も長さが制限されるため、生徒や教室の出力をコピーしても読みやすさを保てます。コンパクト印刷ビューは同じスナップショットデータを使い、日付、シード、現在の段階、ダイス、選択した抜粋を紙の記録向けに HTML エスケープされたブラウザー文書として配置します。

ローカルセッション履歴は、保存したスナップショットの直近 10 件だけをこのブラウザー内に保存します。保存項目は ISO タイムスタンプ、簡潔なタイトル、任意の進行役タグ、任意のアーカイブラベル、詳細アクション付きで新しい順に表示されます。詳細パネルは、表示中の選択済みスナップショットについて、エスケープ済みメタデータと完全なスナップショット本文を表示するため、アクティブなダイス結果を置き換えずに古い記録をコピーまたは印刷できます。タグは前後の空白を取り除き、カンマまたは改行で分割し、大文字小文字を区別せず重複を取り除きながら最初の表記を残し、最大 8 個の短いラベルに制限されます。アーカイブラベルは空白、classroom、event、draft、assessment follow-up に限定されます。タグやアーカイブラベルのない旧履歴は空タグとラベルなしとして読み込まれます。タグフィルターとアーカイブラベルフィルターは表示中の記録を制限し、コピーされる履歴リストや JSON エクスポートも現在表示中の集合だけを反映します。JSON エクスポートには schema とバージョンのマーカーが含まれます。インポートはそのラッパーと各項目を検証し、未知のアーカイブラベルを拒否してから、このブラウザーの保存履歴を置き換えます。インポートされた項目は、通常保存と同じタイトル、安定 ID、タグ、アーカイブラベル、新しい順、最大 10 件のルールで正規化されます。

カスタム単語リストを使うには、6 種類すべてを含む JSON を貼り付けます。

```json
{
  "character": ["curious pilot"],
  "want": ["to find dawn"],
  "setting": ["clock market"],
  "obstacle": ["a locked moon"],
  "object": ["silver key"],
  "twist": ["the map is alive"]
}
```

**Import word bank** をクリックすると検証と正規化を行います。**Copy/export word bank** をクリックすると、現在有効な正規化済み JSON をコピーできます。

同じブラウザーでカスタム単語リストを再利用するには、プリセット名を入力し、必要に応じて対象年齢、ジャンル、教室での文脈などのプリセットメモを追加して **Save preset** をクリックします。名前とメモは前後の空白が取り除かれます。名前は空にはできず、同じ名前を使うと既存プリセットを意図的に上書きします。保存済みプリセットを選ぶとメモが表示されます。**Load preset** をクリックすると、ロック済みダイスを保持したまま単語リストとメモを適用できます。**Delete preset** をクリックすると、現在の単語リストを変えずにそのプリセットを削除できます。

## 設定

設定は不要です。アプリはローカルブラウザーで動作し、リモート API を呼びません。組み込みの教室テンプレートはソースに同梱され、ローカル UI 状態だけを適用します。セッションスナップショットはローカルで整形され、ブラウザーのクリップボード経由でコピーまたはブラウザー印刷ウィンドウへ送られます。ローカルセッション履歴は最近のスナップショット本文、正規化済み進行役タグ、検証済みアーカイブラベルをバージョン付きの `localStorage` に保存します。保存領域が使えない場合やデータが壊れている場合は、安全な状態メッセージを表示してクラッシュせずに続行します。履歴 JSON のインポート/エクスポートはクリップボードとテキストエリアだけを使い、`story-dice-lab.session-history` schema マーカーとバージョン `1` を検証し、未知のアーカイブラベルを拒否し、検証後にローカルブラウザー履歴だけを置き換えます。カスタム単語リストの JSON、名前付きプリセット、任意のプリセットメモはブラウザー内だけで処理されます。ライブ進行役タイマー表示は手動で段階送りし、バックグラウンドのタイミングサービスは使いません。プリセットもバージョン付きの `localStorage` を使います。保存領域が使えない場合やデータが壊れている場合は、安全に不正データを無視し、インポート/エクスポート機能は使い続けられます。メモはプリセットのメタデータとして保存され、エクスポートされる単語リスト JSON には追加されません。
