# Story Dice Lab

[English](README.md) | [中文](README-zh.md) | [日本語](README-ja.md)


Story Dice Lab は、決定的に再現できる創作プロンプトを振るためのローカルファーストなブラウザーアプリです。

## 課題と動機

作家、教師、テーブルトークの進行役は、アカウントやネットワーク接続なしで、遊び心があり再現できて共有しやすいプロンプトをすばやく必要とすることがあります。

## 機能

- 6 種類のプロンプトダイス：人物、目的、舞台、障害、物、ひねり。
- シードによる決定的なロールで、ワークショップの prompts を再利用可能。
- すべてのダイス、または 1 つのダイスだけを振り直し可能。
- ダイスをロックして、「全体を振り直す」ときに良い案を保持。
- コンパクトなプレーンテキストのプロンプトをコピー可能。
- シード、6 種類のダイス、場面作りのための 3 つの問いを含む、決定的で印刷しやすいワークショップ配布資料をコピー可能。
- 25 分の決定的な進行役用アジェンダをコピー可能。時間配分された段階と、ダイスカテゴリを場面の判断につなげるメモを含みます。
- Markdown の影響を受ける文字をダイス値でエスケープし、同じワークショップの問いを含む Markdown プロンプトをコピー可能。
- 現在のプロンプトを、操作 UI を隠したワークショップ向けブラウザー印刷シートとして印刷可能。
- シードとロック済みダイスを復元できる共有用 URL ハッシュをコピー可能。
- 6 種類のダイスカテゴリに対応したカスタム JSON 単語リストをインポートし、正規化済み JSON をコピー/エクスポート可能。
- アクセシブルでキーボード操作しやすいコントロール。

## インストール

Story Dice Lab は GitHub のみで公開されています。npm には公開していないため、検証済みの `npm install -g` や `npx` コマンドはありません。

```bash
git clone https://github.com/codecat-ai/story-dice-lab.git
cd story-dice-lab
npm ci
```

## クイックスタート

```bash
npm run dev
```

ターミナルに表示されるローカルの Vite URL を開きます。

## 例

シード `moonlit workshop` を使い、舞台をロックしてから、場面に合うまで他のダイスを振り直します。**Copy handout** をクリックすると印刷しやすいワークショップ配布資料をコピーでき、**Copy agenda** をクリックすると教師やライティンググループの進行役向けの 25 分の場面スプリントアジェンダをコピーできます。**Copy Markdown** をクリックするとノートや issue スレッド向けの Markdown プロンプトをコピーできます。**Print prompt sheet** をクリックすると現在のプロンプトのブラウザー印刷フローを開けます。**Copy share link** をクリックすると `#seed=moonlit+workshop&locked=setting` のような URL ハッシュを保存または共有できます。

アジェンダのプレビューには、シード、6 種類すべてのダイス、合計 25 分になる 5 つの時間配分、人物/目的、障害/舞台、物/ひねりを具体的な場面選択につなげる進行メモが含まれます。

カスタム単語リストを使うには、6 種類すべてを含む JSON を貼り付けます。

```json
{
  "character": ["curious pilot"],
  "want": ["to find dawn"],
  "setting": ["clock market"],
  "obstacle": ["a locked moon"],
  "object": ["silver key"],
  "twist": ["the map is alive"]
}
```

**Import word bank** をクリックすると検証と正規化を行います。**Copy/export word bank** をクリックすると、現在有効な正規化済み JSON をコピーできます。

## 設定

設定は不要です。アプリはローカルブラウザーで動作し、リモート API を呼びません。カスタム単語リストの JSON はブラウザー内だけで処理されます。

## 開発

```bash
npm ci
npm run lint
npm run typecheck
npm test -- --run
npm run build
```

## テスト

振る舞いのテストは `tests/storyDice.test.ts` にあり、決定性、ロック動作、単一ダイスの振り直し、プロンプト整形、ワークショップ配布資料のエクスポート、進行役用アジェンダのエクスポートと時間配分の拡大縮小、Markdown プロンプトのエクスポート、印刷レイアウトの整形、ブラウザー印刷の起動、カスタム単語リストのインポート/エクスポートを確認します。

## ロードマップ

- カスタムのスプリント時間やタイトルなど、UI 上の任意の進行役用アジェンダ設定。
- 教室向けの追加印刷レイアウト。
