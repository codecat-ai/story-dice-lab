# Story Dice Lab

[English](README.md) | [中文](README-zh.md) | [日本語](README-ja.md)

Story Dice Lab 是一个本地优先的浏览器应用，用来生成确定性的创意写作提示。

## 问题与动机

写作者、教师和桌游主持人经常需要快速、有趣、可复现且便于分享的提示，同时不想依赖账号或网络请求。

## 功能

- 六类提示骰子：角色、目标、场景、阻碍、物件和反转。
- 基于种子的确定性结果，适合课堂和工作坊复用。
- 可一次重掷全部骰子，也可单独重掷某一个骰子。
- 可锁定骰子，让“重掷全部”保留最有用的想法。
- 可复制紧凑的纯文本提示。
- 可复制确定性的五拍场景大纲，用全部六类骰子生成开场画面、欲望、复杂化、转折点和结尾钩子。
- 可复制确定性的可打印工作坊讲义，包含种子、六类骰子和三个场景构思问题。
- 可复制确定性的主持人议程，可编辑标题和总分钟数，并包含计时阶段以及把骰子类别连接到场景决策的提示。
- 可复制面向主持人的议程阶段计时卡片，按同一总分钟数缩放，并适合现场勾选推进。
- 可打印带虚线裁切线的主持人计时卡片版式，复用议程标题和缩放后的阶段分钟数。
- 可显示用于现场投影的大字主持人计时界面，数据来自同一组议程阶段，并可用上一阶段、下一阶段和重置按钮手动控制。
- 可复制确定性的课堂修订卡，可编辑标题；每类骰子一张卡，包含当前值、修订任务和反思问题。
- 可打印带虚线裁切线的课堂修订卡版式；每类骰子一张卡，并复用同一标题、种子和当前结果。
- 可复制确定性的小组同伴评议角色卡，可编辑评议轮标题，并用当前骰子生成便于主持的角色任务。
- 可打印带虚线裁切线的小组同伴评议角色卡版式。
- 可复制紧凑且确定性的评议后行动计划，可编辑标题，包含三个有优先级的下一步和一句修订承诺。
- 可复制 Markdown 提示，其中骰子值会转义 Markdown 敏感字符，并复用同样的工作坊问题。
- 可将当前提示作为适合工作坊的浏览器打印页打印，并在打印时隐藏控件。
- 可复制可分享的 URL hash，用于恢复种子和锁定骰子。
- 可导入包含六类骰子的自定义 JSON 词库，并复制/导出规范化后的 JSON。
- 可在浏览器存储中保存、加载和删除带可选备注的命名本地词库预设，便于不同班级、类型或工作坊小组复用。
- 可应用内置课堂会话模板，为重复工作坊预填种子、议程标题、总分钟数、模板词库和使用备注。
- 可复制本地 Markdown 主持会话快照，把当前骰子、当前计时阶段、预设备注和已勾选的课堂产物摘录打包，便于工作坊后记录。
- 可打印当前主持会话快照的紧凑浏览器页面，便于纸质工作坊记录。
- 可在浏览器本地会话历史中保存最多 10 个近期快照，按最新优先查看时间戳和标题，复制简洁历史列表，复制可迁移的历史 JSON，从另一浏览器导入已验证的历史 JSON，或清空历史。
- 可使用可见的现场主持键盘快捷键：`r` 重掷未锁定骰子，`l` 切换当前聚焦骰子的锁定状态，`[` 和 `]` 切换计时阶段，`c` 复制当前提示，`?` 显示或隐藏快捷键帮助。
- 可访问、支持键盘操作的控件。

## 安装

Story Dice Lab 目前只发布在 GitHub。它尚未发布到 npm，因此没有经过验证的 `npm install -g` 或 `npx` 命令。

```bash
git clone https://github.com/codecat-ai/story-dice-lab.git
cd story-dice-lab
npm ci
```

## 快速开始

```bash
npm run dev
```

打开终端中显示的本地 Vite 地址。

按 `?` 或点击 **Show shortcuts** 可显示现场主持快捷键面板。正在表单字段中输入，或按下 Ctrl、Meta、Alt 时，快捷键会被忽略。

## 示例

使用种子 `moonlit workshop`，锁定场景，然后重掷其他骰子，直到提示适合你的场景。选择一个课堂模板并点击 **Apply template**，即可预填可复用的工作坊种子、模板词库、议程标题和总分钟数；应用模板会清除锁定骰子，并把现场计时器重置到第 1 阶段。点击 **Copy outline** 可复制五拍场景大纲，点击 **Copy handout** 可复制可打印的工作坊讲义，在点击 **Copy agenda** 前设置议程标题和总分钟数，即可复制供教师或写作小组主持人使用的场景冲刺议程；投影当前阶段时，可使用大字现场计时界面的 **Previous**、**Reset** 和 **Next** 按钮，也可按 `[` 和 `]` 用键盘切换阶段。按 `r` 可重掷未锁定骰子；将焦点放在某张骰子卡片或其控件上，再按 `l` 可切换该骰子的锁定；按 `c` 可复制当前提示；按 `?` 可显示或隐藏快捷键帮助。点击 **Copy timer cards** 可用同一议程设置复制逐阶段计时卡片；点击 **Print timer-card layout** 可打印带虚线裁切线的阶段卡片；在点击 **Copy revision cards** 前设置修订卡标题，可复制六张用于同伴反馈或第二轮写作的修订卡；点击 **Print revision-card layout** 可按每类骰子打印一张可裁切的修订卡；在点击 **Copy peer role cards** 前设置同伴角色卡标题，可为小组评议分配任务；点击 **Print peer role-card layout** 可打印可裁切的角色卡；在点击 **Copy action plan** 前设置行动计划标题，可复制三条基于评议的下一步；勾选需要的产物摘录并点击 **Copy session snapshot**，即可复制一份 Markdown 工作坊后记录；点击 **Print session snapshot** 可为同一个当前快照打开紧凑的浏览器打印页；点击 **Save current snapshot** 可把当前快照保存到本地会话历史，点击 **Copy history list** 可复制最新优先的已保存快照列表，点击 **Copy history JSON** 可复制带版本的可迁移 JSON，把兼容 JSON 粘贴到 **Paste/import history JSON** 并点击 **Import history** 会替换此浏览器保存的历史，点击 **Clear history** 可从此浏览器移除已保存快照；点击 **Copy Markdown** 可将 Markdown 提示复制到笔记或 issue 线程中，点击 **Print prompt sheet** 可为当前提示打开浏览器打印流程，或点击 **Copy share link** 保存或发送类似 `#seed=moonlit+workshop&locked=setting` 的 URL hash。

大纲预览包含种子和五个节拍：开场画面、欲望、复杂化、转折点和结尾钩子。这些节拍会共同复用当前结果中的角色、目标、场景、阻碍、物件和反转。

议程预览包含种子、六类骰子、会按所选总分钟数缩放的五个计时阶段，以及把角色/目标、阻碍/场景、物件/反转连接到具体场景选择的主持人提示。

计时卡片使用与议程相同的标题、种子、总分钟数和缩放后的阶段时长。复制出的卡片包含阶段标签、简洁的主持人提示，以及用于现场推进的复选框/行动行。打印版式会把同一组确定性卡片数据排成双栏页面，并带虚线裁切线。

现场主持人计时显示使用与复制和打印计时卡片相同的议程数据。它显示当前阶段标签、大字阶段名称、分钟数、主持人提示和行动检查，并提供上一阶段、重置和下一阶段控件。它有意采用手动推进；MVP 不需要实时倒计时。

修订卡会在提供时包含自定义标题，并包含种子和六张编号卡片。角色卡关注主动性，目标卡提高利害关系，场景卡加入感官细节，阻碍卡升级压力，物件卡要求具体行动，反转卡追问后果。打印版式会把同一组确定性卡片数据排成双栏页面，并带虚线裁切线，便于工作坊裁剪。

同伴角色卡会在提供时包含自定义标题，并包含种子和四个小组任务：Connector、Detail Coach、Stakes Coach 和 Twist Tracker。每个角色都会使用当前骰子，让评议聚焦在当前提示上，而不是泛泛反馈。打印版式会把同一组确定性卡片数据排成双栏页面，并带虚线裁切线。

行动计划会在提供时包含自定义标题，并包含种子、三条编号下一步和一句承诺。三条步骤会把同伴角色反馈焦点连接回骰子类别：Connector 对应角色/目标，Detail Coach 对应场景/物件，Stakes Coach 对应阻碍/反转。

会话快照是给主持人在现场活动结束后粘贴使用的 Markdown 记录。它包含调用方提供的日期标签、当前种子和骰子、当前主持人计时阶段、当前预设名称和备注，以及已勾选课堂产物的短摘录。用户输入字段会折叠为单行并进行 Markdown 安全处理，产物摘录也会限制长度，让复制的学生或课堂输出保持易读。紧凑打印视图使用同一份快照状态，会对用户提供的内容进行 HTML 转义，限制过长备注和产物行，并写入一个自包含的本地浏览器打印文档。

本地会话历史只在当前浏览器中保存最近 10 个已保存快照。条目按最新优先显示 ISO 时间戳和简洁标题；复制的历史列表是纯文本，便于在导出或清空前快速留档。JSON 导出包含 schema 和版本标记；导入会先验证这个包装结构和每个条目，然后替换当前浏览器保存的历史。导入条目会复用常规保存使用的标题、稳定 ID、最新优先和最多 10 条规则进行规范化。

若要使用自定义词库，请粘贴包含全部六类的 JSON：

```json
{
  "character": ["curious pilot"],
  "want": ["to find dawn"],
  "setting": ["clock market"],
  "obstacle": ["a locked moon"],
  "object": ["silver key"],
  "twist": ["the map is alive"]
}
```

点击 **Import word bank** 验证并规范化词库。点击 **Copy/export word bank** 复制当前启用的规范化 JSON。

若要在同一浏览器中复用自定义词库，请输入预设名称，也可添加年龄段、类型或课堂语境等预设备注，然后点击 **Save preset**。名称和备注都会被去除首尾空白；名称不能为空，重复名称会有意覆盖已有预设。选择已保存的预设会显示其备注；点击 **Load preset** 可应用该词库和备注，同时保留已锁定的骰子；点击 **Delete preset** 可删除该预设，且不会改变当前词库。

## 配置

无需配置。应用在本地浏览器中运行，不调用远程 API。内置课堂模板随源码打包，只会应用本地 UI 状态。会话快照在本地格式化，通过浏览器剪贴板复制，并通过注入的本地浏览器打印文档打印。本地会话历史会把近期快照文本存入带版本的 `localStorage`；如果存储不可用或数据损坏，应用会显示安全状态并继续运行，不会崩溃。历史 JSON 导入/导出只使用剪贴板和文本框，会验证 `story-dice-lab.session-history` schema 标记和版本 `1`，并且只在验证通过后替换本地浏览器历史。自定义词库 JSON、命名预设以及可选预设备注都只在浏览器本地处理。现场主持人计时显示是手动推进的，不使用后台计时服务。预设也使用带版本的 `localStorage`；如果存储不可用或数据损坏，应用会安全忽略异常数据，并保留导入/导出功能。备注作为预设元数据保存，不会加入导出的词库 JSON。
