# Story Dice Lab

[English](README.md) | [中文](README-zh.md) | [日本語](README-ja.md)

Story Dice Lab 是一个本地优先的浏览器应用，用来生成确定性的创意写作提示。

## 问题与动机

写作者、教师和桌游主持人经常需要快速、有趣、可复现且便于分享的提示，同时不想依赖账号或网络请求。

## 功能

- 六类提示骰子：角色、目标、场景、阻碍、物件和反转。
- 基于种子的确定性结果，适合课堂和工作坊复用。
- 可一次重掷全部骰子，也可单独重掷某一个骰子。
- 可锁定骰子，让“重掷全部”保留最有用的想法。
- 可复制紧凑的纯文本提示。
- 可复制确定性的五拍场景大纲，用全部六类骰子生成开场画面、欲望、复杂化、转折点和结尾钩子。
- 可复制确定性的可打印工作坊讲义，包含种子、六类骰子和三个场景构思问题。
- 可复制确定性的主持人议程，可编辑标题和总分钟数，并包含计时阶段以及把骰子类别连接到场景决策的提示。
- 可复制面向主持人的议程阶段计时卡片，按同一总分钟数缩放，并适合现场勾选推进。
- 可打印带虚线裁切线的主持人计时卡片版式，复用议程标题和缩放后的阶段分钟数。
- 可显示用于现场投影的大字主持人计时界面，数据来自同一组议程阶段，并可用上一阶段、下一阶段和重置按钮手动控制。
- 可复制确定性的课堂修订卡，可编辑标题；每类骰子一张卡，包含当前值、修订任务和反思问题。
- 可打印带虚线裁切线的课堂修订卡版式；每类骰子一张卡，并复用同一标题、种子和当前结果。
- 可复制确定性的小组同伴评议角色卡，可编辑评议轮标题，并用当前骰子生成便于主持的角色任务。
- 可打印带虚线裁切线的小组同伴评议角色卡版式。
- 可复制紧凑且确定性的评议后行动计划，可编辑标题，包含三个有优先级的下一步和一句修订承诺。
- 可复制 Markdown 提示，其中骰子值会转义 Markdown 敏感字符，并复用同样的工作坊问题。
- 可将当前提示作为适合工作坊的浏览器打印页打印，并在打印时隐藏控件。
- 可复制可分享的 URL hash，用于恢复种子和锁定骰子。
- 可导入包含六类骰子的自定义 JSON 词库，并复制/导出规范化后的 JSON。
- 可在浏览器存储中保存、加载和删除带可选备注的命名本地词库预设，便于不同班级、类型或工作坊小组复用。
- 可应用内置课堂会话模板，为重复工作坊预填种子、议程标题、总分钟数、模板词库和使用备注。
- 可复制和粘贴带版本的本地模板包，让教研组或写作中心无需账号或网络即可共享课堂模板和词库预设；存储可用时，导入的课堂模板会保存在此浏览器中，并可在本地清除。
- 可复制本地 Markdown 主持会话快照，把当前骰子、当前计时阶段、预设备注和已勾选的课堂产物摘录打包，便于工作坊后记录。
- 可打印当前主持会话快照的紧凑浏览器页面，便于纸质工作坊记录。
- 可在浏览器本地会话历史中保存最多 10 个带可选主持人标签和存档标签的近期快照，按标签或存档标签筛选记录，在仅浏览器 UI 状态中按标题和快照 Markdown 正文搜索，打开已保存快照的详情面板，在不替换当前骰子结果的情况下复制或打印旧记录，复制当前可见的简洁历史列表，复制当前可见的可迁移历史 JSON，打印当前可见筛选集合的紧凑批量讲义，从另一浏览器导入已验证的历史 JSON，或清空历史。
- 当清空已保存会话历史、删除已保存预设或清除导入模板且可能丢失本地数据时，会显示简洁的仅浏览器备份提醒。
- 可使用可见的现场主持键盘快捷键：`r` 重掷未锁定骰子，`l` 切换当前聚焦骰子的锁定状态，`[` 和 `]` 切换计时阶段，`c` 复制当前提示，`?` 显示或隐藏快捷键帮助。
- 可访问、支持键盘操作的控件。

## 安装

Story Dice Lab 目前只发布在 GitHub。它尚未发布到 npm，因此没有经过验证的 `npm install -g` 或 `npx` 命令。

```bash
git clone https://github.com/codecat-ai/story-dice-lab.git
cd story-dice-lab
npm ci
```

## 快速开始

```bash
npm run dev
```

打开终端中显示的本地 Vite 地址。

按 `?` 或点击 **Show shortcuts** 可显示现场主持快捷键面板。正在表单字段中输入，或按下 Ctrl、Meta、Alt 时，快捷键会被忽略。

## 示例

使用种子 `moonlit workshop`，锁定场景，然后重掷其他骰子，直到提示适合你的场景。选择一个课堂模板并点击 **Apply template**，即可预填可复用的工作坊种子、模板词库、议程标题和总分钟数；应用模板会清除锁定骰子，并把现场计时器重置到第 1 阶段。点击 **Copy template pack** 可把当前课堂模板和已保存的本地词库预设复制为可迁移 JSON；也可把共享包粘贴到 **Paste/import pack JSON** 并点击 **Import template pack**，加入其中的模板，并在浏览器存储可用时把规范化后的导入模板和预设保存到本地。若存储不可用，状态文本会说明导入模板仅限当前会话使用。点击 **Copy outline** 可复制五拍场景大纲，点击 **Copy handout** 可复制可打印的工作坊讲义，在点击 **Copy agenda** 前设置议程标题和总分钟数，即可复制供教师或写作小组主持人使用的场景冲刺议程；投影当前阶段时，可使用大字现场计时界面的 **Previous**、**Reset** 和 **Next** 按钮，也可按 `[` 和 `]` 用键盘切换阶段。按 `r` 可重掷未锁定骰子；将焦点放在某张骰子卡片或其控件上，再按 `l` 可切换该骰子的锁定；按 `c` 可复制当前提示；按 `?` 可显示或隐藏快捷键帮助。点击 **Copy timer cards** 可用同一议程设置复制逐阶段计时卡片；点击 **Print timer-card layout** 可打印带虚线裁切线的阶段卡片；在点击 **Copy revision cards** 前设置修订卡标题，可复制六张用于同伴反馈或第二轮写作的修订卡；点击 **Print revision-card layout** 可按每类骰子打印一张可裁切的修订卡；在点击 **Copy peer role cards** 前设置同伴角色卡标题，可为小组评议分配任务；点击 **Print peer role-card layout** 可打印可裁切的角色卡；在点击 **Copy action plan** 前设置行动计划标题，可复制三条基于评议的下一步；勾选需要的产物摘录并点击 **Copy session snapshot**，即可复制一份 Markdown 工作坊后记录；点击 **Print session snapshot** 可为同一个当前快照打开紧凑的浏览器打印页；在点击 **Save current snapshot** 前输入可选的逗号或换行分隔标签，例如班级、群组、活动或类型，并选择可选的 **Archive label**（classroom、event、draft 或 assessment follow-up），即可把当前快照保存到本地会话历史；选择 **Filter saved snapshots by tag** 或 **Filter saved snapshots by archive label**，并在 **Search saved snapshots** 中输入内容，可按标题或快照 Markdown 正文显示聚焦后的已保存记录；点击某个可见已保存快照上的 **View details** 可查看其已转义标题、ISO 时间、标签、存档标签和完整内容，然后使用 **Copy saved snapshot** 或 **Print saved snapshot**，且不会替换当前骰子结果；点击 **Copy history list** 可复制当前可见的最新优先快照列表；点击 **Copy history JSON** 可复制当前可见的带版本可迁移 JSON；把兼容 JSON 粘贴到 **Paste/import history JSON** 并点击 **Import history** 会替换此浏览器保存的历史，点击 **Clear history** 可从此浏览器移除已保存快照；点击 **Copy Markdown** 可将 Markdown 提示复制到笔记或 issue 线程中，点击 **Print prompt sheet** 可为当前提示打开浏览器打印流程，或点击 **Copy share link** 保存或发送类似 `#seed=moonlit+workshop&locked=setting` 的 URL hash。

大纲预览包含种子和五个节拍：开场画面、欲望、复杂化、转折点和结尾钩子。这些节拍会共同复用当前结果中的角色、目标、场景、阻碍、物件和反转。

议程预览包含种子、六类骰子、会按所选总分钟数缩放的五个计时阶段，以及把角色/目标、阻碍/场景、物件/反转连接到具体场景选择的主持人提示。

计时卡片使用与议程相同的标题、种子、总分钟数和缩放后的阶段时长。复制出的卡片包含阶段标签、简洁的主持人提示，以及用于现场推进的复选框/行动行。打印版式会把同一组确定性卡片数据排成双栏页面，并带虚线裁切线。

现场主持人计时显示使用与复制和打印计时卡片相同的议程数据。它显示当前阶段标签、大字阶段名称、分钟数、主持人提示和行动检查，并提供上一阶段、重置和下一阶段控件。它有意采用手动推进；MVP 不需要实时倒计时。

修订卡会在提供时包含自定义标题，并包含种子和六张编号卡片。角色卡关注主动性，目标卡提高利害关系，场景卡加入感官细节，阻碍卡升级压力，物件卡要求具体行动，反转卡追问后果。打印版式会把同一组确定性卡片数据排成双栏页面，并带虚线裁切线，便于工作坊裁剪。

同伴角色卡会在提供时包含自定义标题，并包含种子和四个小组任务：Connector、Detail Coach、Stakes Coach 和 Twist Tracker。每个角色都会使用当前骰子，让评议聚焦在当前提示上，而不是泛泛反馈。打印版式会把同一组确定性卡片数据排成双栏页面，并带虚线裁切线。

行动计划会在提供时包含自定义标题，并包含种子、三条编号下一步和一句承诺。三条步骤会把同伴角色反馈焦点连接回骰子类别：Connector 对应角色/目标，Detail Coach 对应场景/物件，Stakes Coach 对应阻碍/反转。

会话快照是给主持人在现场活动结束后粘贴使用的 Markdown 记录。它包含调用方提供的日期标签、当前种子和骰子、当前主持人计时阶段、当前预设名称和备注，以及已勾选课堂产物的短摘录。用户输入字段会折叠为单行并进行 Markdown 安全处理，产物摘录也会限制长度，让复制的学生或课堂输出保持易读。紧凑打印视图使用同一份快照状态，会对用户提供的内容进行 HTML 转义，限制过长备注和产物行，并写入一个自包含的本地浏览器打印文档。

本地会话历史只在当前浏览器中保存最近 10 个已保存快照。条目按最新优先显示 ISO 时间戳、简洁标题、可选主持人标签、可选存档标签和详情操作。详情面板会渲染当前可见的已选快照，包含转义后的元数据和完整快照内容，因此可以复制或打印旧记录，而不会替换当前骰子结果。标签会去除首尾空白，按逗号或换行拆分，按大小写不敏感方式去重并保留首次拼写，最多保存 8 个，并限制为短标签。存档标签只允许空白、classroom、event、draft 或 assessment follow-up。没有标签或存档标签的旧历史会以空标签和无存档标签加载。标签筛选和存档标签筛选会与按标题和快照 Markdown 正文进行的去空白、大小写不敏感搜索组合使用，复制历史列表、JSON 导出和批量打印讲义都只包含当前可见集合，不会泄露被隐藏的记录。批量打印视图会转义用户内容、限制很长的快照正文，并在筛选隐藏所有记录时生成空状态讲义。JSON 导出包含 schema 和版本标记；导入会先验证这个包装结构和每个条目，并拒绝任意未知存档标签，然后替换当前浏览器保存的历史。导入条目会复用常规保存使用的标题、稳定 ID、标签、存档标签、最新优先和最多 10 条规则进行规范化。

若要使用自定义词库，请粘贴包含全部六类的 JSON：

```json
{
  "character": ["curious pilot"],
  "want": ["to find dawn"],
  "setting": ["clock market"],
  "obstacle": ["a locked moon"],
  "object": ["silver key"],
  "twist": ["the map is alive"]
}
```

点击 **Import word bank** 验证并规范化词库。点击 **Copy/export word bank** 复制当前启用的规范化 JSON。

若要在同一浏览器中复用自定义词库，请输入预设名称，也可添加年龄段、类型或课堂语境等预设备注，然后点击 **Save preset**。名称和备注都会被去除首尾空白；名称不能为空，重复名称会有意覆盖已有预设。选择已保存的预设会显示其备注；点击 **Load preset** 可应用该词库和备注，同时保留已锁定的骰子；点击 **Delete preset** 可删除该预设，且不会改变当前词库。当存在相关本地数据时，破坏性本地操作会先提醒你导出或复制备份，再请求确认。

模板包是便于粘贴的 JSON，用于共享本地工作坊组合。模板包使用 schema `story-dice-lab.template-pack`、版本 `1`、必填标题、可选备注，最多包含 24 个模板和 24 个词库预设。导入会在改变已保存状态前拒绝格式错误 JSON、缺失标题、重复模板或预设名称、过多条目以及过大的分类列表，并用友好的状态文本说明问题。导入的模板会被规范化，与内置模板合并时避免重复 id 或标题，并在存储可用时用带版本的本地键保存；如果存储不可用或写入失败，它们仅在当前会话中可用。**Clear imported templates** 会在备份提醒后只清除此浏览器中的导入模板；内置模板和已保存词库预设会保留。导入的预设仍会在可用时通过现有本地预设存储保存。导出是确定性的：模板按标题/id 排序，预设按名称排序，词库值会被规范化。

## 配置

无需配置。应用在本地浏览器中运行，不调用远程 API。内置课堂模板随源码打包，只会应用本地 UI 状态。模板包通过本地文本框和浏览器剪贴板复制粘贴，验证完全在客户端进行；导入的课堂模板会在存储可用时作为规范化模板写入带版本的 `localStorage`，启动时加载，并在存储缺失、格式错误、版本不受支持或内容无效时安全忽略。导入的词库预设会在可用时使用现有带版本的预设 `localStorage`。会话快照在本地格式化，通过浏览器剪贴板复制，并通过注入的本地浏览器打印文档打印。本地会话历史会把近期快照文本、规范化后的主持人标签和已验证的存档标签存入带版本的 `localStorage`；搜索查询只是浏览器 UI 状态，不会改变存储 schema。如果存储不可用或数据损坏，应用会显示安全状态并继续运行，不会崩溃。历史 JSON 导入/导出只使用剪贴板和文本框，会验证 `story-dice-lab.session-history` schema 标记和版本 `1`，拒绝任意未知存档标签，并且只在验证通过后替换本地浏览器历史。可见历史批量打印只使用当前筛选后的内存记录和注入的本地打印文档；不会增加新的存储字段。自定义词库 JSON、命名预设以及可选预设备注都只在浏览器本地处理。现场主持人计时显示是手动推进的，不使用后台计时服务。预设也使用带版本的 `localStorage`；如果存储不可用或数据损坏，应用会安全忽略异常数据，并保留导入/导出功能。备份提醒只是围绕本地破坏性操作的浏览器确认提示；没有相关本地数据或确认能力不可用时会跳过。备注作为预设元数据保存，不会加入导出的词库 JSON。
