# Story Dice Lab

[English](README.md) | [中文](README-zh.md) | [日本語](README-jp.md)


Story Dice Lab は、決定的に再現できる創作プロンプトを振るためのローカルファーストなブラウザーアプリです。

## 課題と動機

作家、教師、テーブルトークの進行役は、アカウントやネットワーク接続なしで、遊び心があり再現できて共有しやすいプロンプトをすばやく必要とすることがあります。

## 機能

- 6 種類のプロンプトダイス：人物、目的、舞台、障害、物、ひねり。
- シードによる決定的なロールで、ワークショップの prompts を再利用可能。
- すべてのダイス、または 1 つのダイスだけを振り直し可能。
- ダイスをロックして、「全体を振り直す」ときに良い案を保持。
- コンパクトなプレーンテキストのプロンプトをコピー可能。
- シードとロック済みダイスを復元できる共有用 URL ハッシュをコピー可能。
- アクセシブルでキーボード操作しやすいコントロール。

## インストール

Story Dice Lab は GitHub のみで公開されています。npm には公開していないため、検証済みの `npm install -g` や `npx` コマンドはありません。

```bash
git clone https://github.com/codecat-ai/story-dice-lab.git
cd story-dice-lab
npm ci
```

## クイックスタート

```bash
npm run dev
```

ターミナルに表示されるローカルの Vite URL を開きます。

## 例

シード `moonlit workshop` を使い、舞台をロックしてから、場面に合うまで他のダイスを振り直します。**Copy share link** をクリックすると、`#seed=moonlit+workshop&locked=setting` のような URL ハッシュを保存または共有できます。

## 設定

設定は不要です。アプリはローカルブラウザーで動作し、リモート API を呼びません。

## 開発

```bash
npm ci
npm run lint
npm run typecheck
npm test -- --run
npm run build
```

## テスト

振る舞いのテストは `tests/storyDice.test.ts` にあり、決定性、ロック動作、単一ダイスの振り直し、プロンプト整形を確認します。

## ロードマップ

- シードとロック状態を共有できる URL ハッシュ。
- 印刷用プロンプトカード。
- 任意のカスタム単語リストのインポート/エクスポート。

## コントリビュート

Issue や小さな PR を歓迎します。ローカルファースト、アクセシビリティ、振る舞いテストを大切にしてください。
